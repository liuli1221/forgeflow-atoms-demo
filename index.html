ForgeFlow

自然语言 → 可交互网页应用的本地工作台

描述你想要的小工具，ForgeFlow 会为数据管理类应用使用确定性生成器，为游戏和工具类应用调用 真实 DeepSeek LLM，等你确认计划后再生成 HTML / CSS / JS 源码并加载可操作预览。

  • 真实生成：支持 8 类稳定蓝图；计算器、贪吃蛇等开放应用由 DeepSeek 生成真实源码。
  • 先计划后执行：计划可编辑、可检查，点击批准才会动手。
  • 真实可交互：生成的应用支持增删改查、搜索、筛选、统计，数据刷新后仍在。
  • 版本可回溯：每次成功生成形成一个版本，可预览、可一键恢复。
Hybrid Agent DeepSeek 服务端调用 可选账号同步

说明：CRUD 类需求优先走本地确定性流水线；游戏、计算器和未知类型走服务端 DeepSeek。 API Key 只保存在服务端，浏览器无法读取；生成失败不会静默改成通用条目管理器。
